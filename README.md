# Wuniflow Landing

Landing page B2B da **Wuniflow Automations** para captação de leads de Trade Marketing, Field Sales e operações de campo.

## Objetivo
Converter tráfego pago em conversas qualificadas por meio de um **Diagnóstico de Digitalização Operacional**.

## Stack
React + TypeScript + Vite.

## Execução
```bash
npm install
npm run dev
npm run build
```

## Conversão
O formulário valida os campos e abre uma conversa contextualizada no WhatsApp comercial da Wuniflow.

## Próximas integrações
GA4, Google Tag Manager e Meta Pixel devem ser configurados com IDs reais antes da ativação das campanhas.
